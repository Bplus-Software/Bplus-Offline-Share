B+ Share 1.1.9, device-test pre-release

Delete flow
- Plain Delete title and destructive red Delete button. Choices: Delete from this chat / Delete files from this phone. Short final prompts, singular wording for one item, numeric result counts without broken plurals. Arabic and English included. Text-only selection goes directly to local-message confirmation.
- Chat-only deletion removes selected local records, never bytes or another phone. File deletion removes the explicitly confirmed URI only and keeps message/card records. The short permanent-delete warning says it cannot be undone and other phones are unchanged.
- Fixed two source-level gaps: legacy B+ attachment provider previously had no delete support; document-picker URIs were incorrectly sent to generic resolver deletion. Legacy provider now allows same-app deletion only with canonical folder/path checks; document URIs use DocumentsContract.deleteDocument.
- Owned MediaStore downloads use resolver deletion. Protected media can request Android's per-file delete consent on supported versions; result returns to the pending batch. Picker flows preserve granted write access where Android provides it. No broad storage permission, guessed filename match or arbitrary filesystem fallback is added.
- Failure opens a readable result dialog with filename and read-only/refused/missing-reference/cancel explanation. No success claim for failed deletion. Some document/cloud providers and old read-only grants can still refuse; use the phone file manager in that case. The exact URI/permission behind the owner's sent-JPG failure remains unknown. This build does not prove his particular file is deletable.

Emoji
- Replaces five-item emoji list with 156 emoji in six labelled groups: faces, hands, hearts/celebration, nature, food/drink, activities/things.
- Scrollable bounded-height responsive grid, 52dp cells, standard emoji font, 44dp trigger and 12dp added separation from Attach in private/group chat. Inserts at cursor/replaces selection, closes picker, never sends automatically. Emoji appearance depends on the phone font.

Checks and limits
- Clean SDK34 build, versionCode14, original signing certificate, 279 matching EN/AR keys. Seven canonical file-path/deletion tests cover flat/typed paths and traversal/symlink rejection; document/consent/result wiring source checks. Prior 22 gesture, mixed/text/record, sharing, group, nearby, message-network and updater tests pass. Exact released 1.1.8 downloader tested against final candidate redirect/SHA harness.
- The owner's recording/screenshots establish 1.1.8 wording and deletion failures, not that this build fixes his phone. Actual Android delete-consent, provider permissions, real file deletion, emoji layout and 1.1.9 pixels remain unverified. Risk unmeasured. Please test only disposable files, including a file freshly received into B+ Share and one selected sent file.
- Includes prior text multi-selection, gesture re-entry and fixed-position fade-dialog changes. All existing local trusted-network/unencrypted HTTP/group-host/offline/storage/share-delivery/size/resume/checksum limits remain. System consent/pickers/chooser/installer retain Android styling.
- Pre-release, no promotion. 1.1.5 stays normal latest. Install manually over current without uninstalling. Downgrade may require uninstall and lose local chats/settings. No Windows or internet relay changes.
