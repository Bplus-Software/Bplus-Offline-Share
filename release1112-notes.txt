B+ Share 1.1.12, voice UI device-test pre-release

Changes
- Microphone and Send now share one action position in private/group composers: microphone with empty input, Send arrow when text is present. No extra microphone to the side. Holding the empty-input action records; typing uses the normal text-send click. Slide-to-cancel and permission/lifecycle guards remain.
- B+ voice-note cards show the audio player and a compact options menu, without generated filename, M4A label, size or generic tap-to-open footer. The underlying file stays unchanged; generic imported audio files keep metadata. Old B+ voice filenames are recognized for this display treatment.
- Real duration is read from local metadata asynchronously before playback, with loading/unavailable wording instead of an initial false 0:00. Playback still prepares on Play and shows elapsed/total with seeking.
- During recording, a foreground overlay shows a running elapsed timer, live microphone peak-history bars, red recording dot and release/slide hint. Bars use MediaRecorder amplitude samples, not fake random animation. Cancel state is latched; release after a slide discards. Overlay/timer stops when recording ends/cancels or chat leaves.

Validation and limits
- Clean signed build, versionCode17, original signer, 302 matching EN/AR keys. Voice pure-rule tests and composer/metadata/live-amplitude/timer-cleanup source checks pass. All prior receipt/release-choice/gesture/record/path/share/group/nearby/message/updater suites pass; exact released 1.1.11 downloader candidate redirect/SHA harness passed.

Phone screenshot/recording needed before any promotion.
- Includes 1.1.10 private receipt-bound recall/test updater and 1.1.11 voice recording/player. Same foreground-only recording, 0.6-second minimum, five-minute discard safety limit, app-local source retention and local-network/group-host/unencrypted transport limits. New private recall requires both phones updated and newly tracked direct items; no group or old-card recall. No background mic, transcription, cloud upload, internet relay or Windows changes.
