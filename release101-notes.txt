B+ Offline Share 1.0.1, Android device-test pre-release

BPLUS_VERSION_CODE: 24

Android changes:
- One-to-one text is saved to a persistent local queue before network send. The foreground service automatically retries compatible reachable paired devices, including after reopening/restarting. Stable wire IDs and atomic receiver receipts prevent duplicates after a lost acknowledgement.
- Current paired-device display names refresh through authenticated LAN sync. Settings device-name edits update the advertised display name too. Existing peer IDs, tokens and storage paths are preserved.
- Remove device is available in Devices and the chat menu, with confirmation. Removes local pairing and cancels pending text. Keeps local chats/files. Does not erase the other device or cancel a request already on the network. Pair again to reconnect.
- Gray double ticks mean delivered, blue double ticks mean read. Read is recorded only when an incoming row is visible in the active conversation, not from a notification/ping. Legacy sent state uses a single tick.

Compatibility/limits:
- Both apps need compatible /sync v2 support for durable text retry and receipts. Older peers do not receive automatic retries, to avoid duplicates. Untracked old failed messages stay manual. Files/groups are not automatically retried by this extension.
- Still trusted same-LAN HTTP, not encrypted and not internet delivery. Both services must be running/reachable at their saved LAN addresses. IP changes/router isolation may need pairing again. Force-stop, battery restrictions or a stopped service prevent background retries; queue resumes when service starts. Retry backoff is bounded to60seconds after repeated failures.
- Last100 eligible sent/delivered records are queried for read status per peer. Older messages can retain delivered status.
- Higher Android versionCode24, same com.bplus.share package and original signer, supports normal installation over1.0.0. Do not uninstall/clear app data. Because the repository is now Bplus-Offline-Share, the installed1.0.0 updater selects this version but rejects its renamed download path. This ONE upgrade needs manual APK installation OVER the installed app, no uninstall.1.0.1 accepts both exact repo paths for future in-app updates. Enable test versions for future pre-releases; official-only remains1.0.0. Installer and actual data retention not phone-tested.

Validation:

- Exact released1.0.0 updater selector tested with synthetic1.0.1/code24 pre-release metadata plus a Windows.exe asset: chooses APK with test channel ON, no beta offer when OFF, no self-update.
- Existing message network, groups, nearby, recall, sharing, import, version, formatter and reset suites passed.
- Android disk/lifecycle/UI pixels, device upgrade/data retention, two physical phones and Android/Windows sync remain unverified. Pre-release only, no official promotion without device evidence.
