B+ Share 1.1.8, device-test pre-release

Changes
- Includes all 1.1.7 changes below. Dialog content/font/background/bounded width and centered gravity are prepared before the window is shown, not resized after entry. Explicit short alpha fade replaces platform movement/scale animation. Keyboard does not pan/resize the dialog window. This targets the reported dialog jump; actual phone animation still needs verification.
- Selection gestures latch their owner at finger-down. A long-press that enters selection no longer also deselects on that same finger-up. Repeated select/deselect/re-enter cycles have regression tests. A dragged or cancelled gesture does not count as a toggle. Outside selection mode, short tap still opens a file; long-press starts selection. While selection is active, short tap toggles. When the final item is deselected selection mode closes; long-press again to restart.
- Plain text messages now support long-press multi-select in private/group chats, including text-only conversations. The same opposite-corner check and separate row highlight apply. All selects all chat messages/cards; library All remains the visible file category.
- Delete removes the confirmed selected local messages/cards, never another phone's records or actual bytes. Text-only selection has no disk-delete choice. Mixed selection offers the separate explicitly warned file-byte deletion only for its file entries; that choice leaves message records.
- Share opens Android's chooser with selected texts joined in chat order. Mixed text/files include text as a caption plus readable attachment URIs. A missing attachment blocks mixed sharing; recipient apps may ignore captions. Nothing sends to an external recipient automatically.
- Send selects a paired device, confirms item count/target, and sends texts as new messages and files as copies, retaining originals. Result counts successful items, not devices. Retries can duplicate messages/files; no automatic retry added.
- One selected item now uses singular local-removal wording. Selection send labels/counts work for text and files.

Validation and caveats
- Clean build, original signer, versionCode12. Dialog setup/animation source checks; twenty-two pure gesture tests include repeated re-entry, same-UP protection, tap, drag and cancel. Pure mixed/text record deletion tests plus prior record/share/group/nearby/message/updater suites pass. Exact released 1.1.7 downloader recognizes/downloads the candidate through redirect/SHA harness.
- Inspected the owner's second 1.1.6 recording, which exposed the regression. The same-touch ownership defect is reproduced in a deterministic gesture harness, not a full Android runtime reproduction. No actual 1.1.8 Android pixels or gestures verified here; phone recording is still required before promotion. Risk unmeasured.
- Test-only pre-release. 1.1.5 stays normal latest. 1.1.6 is not promoted. Install manually over the existing app without uninstalling. In-app latest will not offer this candidate. Downgrade can require uninstalling and lose local chats/settings.
- Existing local-network, unencrypted HTTP, group-host/reachability, no offline queue/history sync, old missing file-reference, OS sound/permissions, share delivery and transfer-size/resume/checksum limits remain. System pickers/chooser/installer keep Android styling. No internet relay or Windows work.
